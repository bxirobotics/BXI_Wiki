# 语音对话使用说明

通过语音与 ELF3 交流：面向机器人说出问题，等待语音回复，再继续下一轮对话。

## 1. 使用前确认

确认机器人处于可对话状态、网络连接正常，并尽量选择安静的环境。说话时面向机器人的麦克风，保持自然、清晰的语速。

## 2. 开始对话

1. 如果机器人需要唤醒，先说交付时告知的唤醒词；无需唤醒时，可直接提问。
2. 说出一句完整的问题，一次表达一个主要意思。
3. 等待机器人回复，回复结束后再继续提问。
4. 如果机器人重新进入等待唤醒状态，再说一次唤醒词后继续交流。

可以先说“你好”，确认机器人能够回应后，再提出其他问题。

## 3. 对话示例

可以尝试以下表达：

- “介绍一下你自己。”
- “给我讲一个简短的故事。”
- “什么是机器人？”
- “请用更简单的话解释一下。”

如果回答与预期不符，可以重新表述问题，补充背景，或说明希望回答得更简短、更容易理解。对话内容和回复效果以实际使用为准。

## 4. 常见问题

| 问题 | 建议处理方式 |
|---|---|
| 说话后没有回应 | 确认机器人处于可对话状态、网络正常；需要唤醒时，先说唤醒词再提问 |
| 唤醒后仍没有回应 | 使用交付时告知的唤醒词，减少周围噪声，面向麦克风清楚地说话 |
| 听不清回复 | 尽量在安静环境中交流；持续听不清或没有声音时联系维护人员 |
| 回答与问题不符 | 用完整句子重新提问，一次只问一个问题，并补充必要背景 |
| 回复较慢 | 等待本轮回复，确认网络正常，避免连续重复提问 |

如果问题持续出现，记录发生时间和当时的对话情况，联系维护人员协助处理。
