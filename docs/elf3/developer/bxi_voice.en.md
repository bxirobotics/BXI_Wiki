# Voice Conversation User Guide

Talk with ELF3 by facing the robot, asking a question, listening to its spoken reply and continuing the conversation.

## 1. Before You Begin

Confirm that the robot is ready for conversation and has network connectivity. Choose a quiet environment where possible. Face the robot's microphone and speak clearly at a natural pace.

## 2. Start a Conversation

1. If the robot requires waking, say the wake phrase provided at delivery. Otherwise, ask directly.
2. Ask a complete question with one main point at a time.
3. Wait for the robot to finish replying before asking the next question.
4. If the robot returns to wake standby, say the wake phrase again to continue.

Start with a simple greeting to confirm that the robot responds, then ask other questions.

## 3. Example Questions

Try requests such as:

- “Introduce yourself.”
- “Tell me a short story.”
- “What is a robot?”
- “Please explain that in simpler words.”

If a reply does not match your expectations, rephrase the question, add context, or ask for a shorter or simpler explanation. Conversation content and results depend on actual use.

## 4. Common Problems

| Problem | Suggested action |
|---|---|
| No response to speech | Confirm the robot is ready for conversation and has network access. If required, say the wake phrase before asking |
| Still no response after waking | Use the wake phrase provided at delivery, reduce background noise and speak clearly toward the microphone |
| Reply is difficult to hear | Move to a quieter environment where possible. Contact maintenance staff if audio remains unclear or absent |
| Reply does not address the question | Ask again in a complete sentence, focus on one question and add necessary context |
| Reply is slow | Wait for the current reply, check network connectivity and avoid repeatedly asking the same question |

If a problem persists, note the time and what happened during the conversation, then contact maintenance staff for assistance.
