# 包装说明

本页用于指导精灵 3 机器人回箱包装。操作前请确认包装箱、缓冲棉、吊架和牵引绳状态完好，并预留足够的操作空间。

!!! warning "操作安全"
    - 建议全程至少 2 人配合操作，吊装和下放过程中保持机器人稳定。
    - 机器人进入包装箱时应缓慢下放，避免碰撞箱体或挤压缓冲棉。
    - 合盖前必须检查箱盖是否自然闭合，严禁强压装箱。

## 包装前准备

| 项目 | 要求 |
| :--- | :--- |
| 人员 | 建议至少 2 人配合操作 |
| 吊装 | 准备吊架及机器人牵引绳 |
| 包装件 | 确认包装箱、各处缓冲棉齐全且位置可识别 |
| 随机附件 | 准备平板、手柄、充电器及腿部缓冲棉 |

## 流程概览

| 步骤 | 操作目标 | 关键检查 |
| :--- | :--- | :--- |
| 1 | 放置随机附件及腿部缓冲棉 | 附件均放入对应空格 |
| 2 | 吊装机器人并放入包装箱 | 背部把手对准缓冲棉凹槽 |
| 3 | 放置手臂及手肘缓冲棉 | 手臂卡入缓冲棉下方槽位 |
| 4 | 放置双腿并完成包装 | 脚尖朝向空格边缘，上盖可自然闭合 |

## 详细步骤

### 1. 放置附件及腿部缓冲棉

**操作要点**

- 将平板、手柄、充电器放入包装箱内对应空格。
- 将腿部缓冲棉按照图示位置放入箱体空格处。

**检查点**

- 各附件不应高出箱体缓冲棉平面。
- 腿部缓冲棉方向应与图示一致。

### 2. 吊装机器人并放入包装箱

**操作要点**

- 物品放置好后，将机器人放在吊架上吊起。
- 将包装箱推到机器人下方，缓慢将机器人下放。
- 待机器人臀部接触到缓冲棉底部后，取掉吊架上方的吊钩。

**人员配合**

- 1 人将机器人背部的牵引绳提起。
- 1 人抬住机器人的双腿。
- 两人配合将机器人背后的把手对准缓冲棉凹槽处下放。
- 放置到位后，取下机器人上方的牵引绳并放在空格处。

**检查点**

- 机器人臀部应落到缓冲棉底部。
- 机器人背部把手应对准缓冲棉凹槽。
- 牵引绳应取下并放入指定空格。

### 3. 放置手臂及手肘缓冲棉

**操作要点**

- 拉动机器人的左右腿，缓慢转动机器人腰部。
- 将机器人手臂放入缓冲棉下方的槽中并卡紧。
- 将手臂、手肘处的缓冲棉放置到位。

**检查点**

- 手臂应完全进入缓冲棉槽位。
- 手肘处缓冲棉不得松动或偏移。
- 调整过程中避免让关节处于极限位置。

![图 3：手臂及手肘缓冲棉放置位置](../assets/elf3/packaging/step-3.png){ width="480" }

<p align="center">图 3</p>

### 4. 放置双腿并完成包装

**操作要点**

- 转动机器人的双腿。
- 将左右腿缓慢放置到图示位置。
- 保持脚尖朝向空格边缘。

**检查点**

- 左右腿位置应与图示一致。
- 脚尖应朝向空格边缘。
- 各处缓冲棉不得被挤出或明显变形。

## 完成检查

!!! warning "锁箱前检查"
    - 锁箱前检查机器人是否仍处于开机状态。
    - 合盖后检查箱盖是否翘起，有异常需及时调整。
    - 严禁强压装箱。正确放置时上盖不会翘起。
    - 如上盖翘起，请检查上盖缓冲棉和脚掌的放置位置是否正确。
