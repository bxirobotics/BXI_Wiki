# 0.3

## 版本与主要功能

适用软件系列 `0.3.x`，配置版本 `0.3`。本表以 `0.3.1` 为参考版本。

主要功能：通过 CAN 读取和配置电机、编码器、校准/测试、控制、保护及 MIT 参数。提供老化测试开关、运行状态与配置 CRC 读取项。

CAN 读写命令、帧格式、状态码和小端数据解析方法见[电机寄存器通信协议](../register_protocol.md)。

出厂默认值列中的 `—` 表示本页未给出已确认的默认值；请结合实际电机型号和设备配置使用，不能将其视为 `0`。
