# 寄存器表

寄存器表按软件版本的前两段 `主版本.次版本` 匹配。同一系列的所有补丁版本共用同一张表，第三段不参与校验。例如 `0.3.1` 和 `0.3.7` 都匹配 `0.3.x`。设备的配置版本应与软件系列一致，可读取寄存器 `0x7C` 确认。
