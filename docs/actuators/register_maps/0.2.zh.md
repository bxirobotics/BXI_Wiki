# 0.2

## 版本与主要功能

适用软件系列 `0.2.x`，配置版本 `0.2`。本表以 `0.2.2` 为参考版本。

主要功能：通过 CAN 读取和配置电机、编码器、校准/测试、控制、保护及 MIT 参数。

寄存器的 CAN 读写命令、帧格式、状态码和小端数据解析方法，请先参阅[电机寄存器通信协议](../register_protocol.md)。

- `type=0`：`int32_t`；`type=1`：`bool`；`type=2`：IEEE754 单精度 `float`；`type=4`：版本号。
- 通信范围 `0`：运行中可读写；`1`：仅菜单或错误状态可写；`2`：系统通信参数，仅菜单或错误状态可写；`3`：只读。
- 写入操作只修改 RAM。需要掉电保存时，应在写入成功后发送 `REG_SAVE`。
- `current_test_enable` 和 `mit_aux_enable` 是运行时开关，不会写入 Flash。执行 `REG_SAVE` 时固件会以 `0` 保存，但不会改变当前 RAM 中的开关状态；上电或重新读取配置后恢复为 `0`。
- 完整 ENCO 构建公开 52 个寄存器。`0x13`、`0x15`、`0x17` 和 `0x18` 仅在 `USE_ENC2=1` 时存在；未启用 ENCO 的构建公开 48 个寄存器。实际数量可通过 `REG_INFO` 查询。
- 通信层主要校验地址、数据类型和写入状态，不会统一检查所有数值的业务范围。修改保护阈值、限幅和控制增益前，请确认目标电机型号及参数要求。

出厂默认值列中的 `—` 表示本页未给出已确认的默认值；请结合实际电机型号和设备配置使用，不能将其视为 `0`。
