# BXI Control App 使用指南（新版）

BXI Control 是用于添加、连接和管理 BXI 机器人的控制应用。本指南以当前 App 的页面与路由实现为准，适用于 Android 和 Windows 版本。

!!! info "下载最新版本"

    Android 版本请从 [BXI 下载站的控制 App 页面](https://download.bxirobotics.cn/%E6%8E%A7%E5%88%B6APP/Android) 下载最新安装包。iOS 版本正在进行内部测试与优化，后续将正式开放。

!!! warning "安全第一"

    遥控、建图、导览、固件升级和远程协助都可能影响机器人状态。开始前请确认机器人周边无人、处于安全姿态，并保持供电和网络稳定。本指南的截图均来自测试环境；设备名称、地址和标识已脱敏。

## 新版与旧版的区别

新版 BXI Control 在保留旧版设备添加、连接、遥控和维护能力的基础上，对页面结构、连接链路和安全能力进行了统一升级。日常使用可按“首页 → 我的设备 → 连接方式 → 设备主页 → 运行模式”的路径完成；固件管理、状态自检和个人中心也有独立、清晰的入口。

- **性能更好**：控制、视频和设备状态功能会随当前连接方式按需加载，减少重复初始化和不必要的等待，使常用操作更直接；
- **冗余代码更少**：新版统一了设备、连接、控制和设置页面中的共用逻辑，减少重复实现，后续功能迭代和问题定位更清晰；
- **稳定性更强**：连接状态、控制输入、视频刷新和会话恢复均有明确的处理边界，降低切换页面、切换网络或短时波动后残留状态带来的风险；
- **设备管理更集中**：首页、设备主页和个人中心按使用场景组织功能，Wi-Fi/蓝牙连接方式、固件升级和状态诊断不再分散在多个入口；
- **安全能力升级**：新版配合升级后的机器人固件启用加密，并支持共享等新能力。加密保护不能替代现场安全措施；账号、密码、设备地址、日志和会话信息仍应按敏感信息妥善保管。

### 旧版机器人必须先完成固件升级

新版 App 检测到机器人仍使用旧版、未加密的固件时，会显示升级提示并引导至固件升级流程。请先完成机器人固件升级，再使用新版 App 的连接、加密及共享等新功能；不要绕过或中断该升级过程。

![检测到旧版机器人时的升级提示（设备列表已脱敏）](../assets/control/app-guide-2026/firmware-upgrade-required-redacted.png)

!!! warning "加密与凭据保护"

    固件升级启用加密后，仍不要在截图、工单、日志或聊天中泄露 Wi-Fi 密码、SSH 密码、设备地址、蓝牙地址、令牌或会话标识。需要分享设备时，请使用 App 提供的授权与共享流程，并只授予必要范围的访问权限。

!!! note "升级后的使用建议"

    新旧版的页面名称和入口位置可能不同。请以新版页面显示的功能为准；不要根据旧版经验跳过固件升级、配网、连接状态或启动前安全检查。

## 1. 首页

### 1.1 首次启动

首次启动时显示欢迎页。可填写手机号码、同意服务协议与隐私政策后获取验证码登录；需要离线部署、现场维护或暂不登录账号时，可点击底部的 **进入本地模式**。本地模式不会自动创建云端账号。

![首次启动欢迎页](../assets/control/app-guide-2026/home-initial.png)

### 1.2 首页功能入口

完成登录或进入本地模式后进入首页。右侧依次提供 **添加设备**、**我的设备**、**固件升级**、**状态自检** 和 **个人中心** 入口；右上角的“本地模式”表示当前使用本机保存的设备绑定信息。

![首页](../assets/control/app-guide-2026/07-home.png)

### 云端模式与本地模式

| 项目 | 云端模式 | 本地模式 |
| --- | --- | --- |
| 身份与数据 | 使用手机验证码登录；设备绑定关系从云端账号加载 | 无需登录；仅使用本机保存的绑定和维修凭据 |
| 设备协作 | 支持设备分享管理、扫码加入分享设备和账号服务 | 不支持通过分享码加入设备 |
| 服务功能 | 可使用工单、未读提醒和账号资料 | 工单会提示需要登录，账号服务不可用 |
| 控制能力 | 经账号授权后连接机器人 | 可直接连接已在本机绑定的局域网或蓝牙机器人 |
| 切换规则 | 登录后自动进入云端模式 | 必须先退出云端账号；切换时 App 会断开现有连接 |

本地模式适合离线或现场维护，设备关系主要保留在当前控制设备；云端模式适合多设备协作、账号管理和服务支持。首页右上出现 **本地模式** 标识时，表示当前处于本地模式。

## 2. 添加机器人

### 2.1 添加设备引导

点击首页的 **添加设备**，先完成以下准备：

1. 开启机器人主控电源，并确保机器人处于安全位置。
2. 在手机或平板上开启蓝牙与定位权限。
3. 将控制设备连接到可用 Wi-Fi；Wi-Fi 控制时，控制设备与机器人应位于同一局域网。
4. 点击 **开始配对** 进入附近机器人扫描页。

![开机与蓝牙连接引导](../assets/control/app-guide-2026/04-add-device.png)

### 2.2 扫描与选择蓝牙设备

扫描页会列出附近可发现的 BXI 机器人及其信号强度。点击目标设备的 **连接** 后，按照页面指引完成配网或绑定。

!!! tip "找不到机器人"

    检查机器人是否已开机，控制设备的蓝牙和定位是否开启，并靠近机器人后点击 **重新搜索**。

![选择要添加的机器人](../assets/control/app-guide-2026/ble-scan.png)

### 2.3 配网与绑定流程

完成蓝牙连接后，App 会进入绑定流程：确认目标机器人、填写或选择 Wi-Fi 信息、等待机器人加入网络。绑定完成后，机器人会出现在 **我的设备**。

!!! warning "不要在配网过程中退出"

    凭据写入与网络切换期间请不要关闭 App、关闭蓝牙或给机器人断电；如失败，请从“添加设备”重新开始扫描。

## 3. 管理与连接设备

### 3.1 我的设备

**我的设备** 以卡片展示已绑定的机器人。点击卡片进入连接方式选择；右侧还可使用“配对新机器人”或“扫描维修凭证”等入口。卡片上的在线状态仅表示当前可发现性，不能替代现场安全检查。

![我的设备](../assets/control/app-guide-2026/my-devices.png)

### 3.2 选择连接方式

选择机器人后，App 提供两种连接方式：

| 方式 | 适用场景 | 能力与限制 |
| --- | --- | --- |
| **Wi-Fi 连接** | 控制设备与机器人在同一局域网 | 推荐方式；支持视频流、状态自检、地图和固件管理 |
| **蓝牙直连** | 无可用局域网或近距离基础控制 | 仅用于近距离基础控制；不支持视频流和部分网络功能 |

![选择连接方式](../assets/control/app-guide-2026/connect-method.png)

### 3.3 Wi-Fi 自动扫描与切换网络

选择 **Wi-Fi 连接**（部分版本显示为“Wi-Fi 控制”）后，App 会先在手机、平板或 PC 当前连接的局域网内自动发现机器人。找到同网段的已绑定机器人后，即可建立控制会话并使用视频、状态自检及固件管理等网络功能。

若机器人需要切换到另一个 Wi-Fi 网络，无需先在 App 中手动填写旧网络信息：

1. 先让手机或平板连接到目标 Wi-Fi；
2. 回到该机器人的连接方式页，点击 **Wi-Fi 连接 / Wi-Fi 控制**；
3. 当 App 发现机器人与控制设备不在同一网络时，会进入 Wi-Fi 配网流程；
4. 按提示确认目标网络并完成配网，等待机器人接入后再重新发起 Wi-Fi 控制。

!!! tip "为什么先连接手机/平板的目标 Wi-Fi"

    App 以控制设备当前网络作为自动扫描和配网的目标网络来源。先切换控制设备网络，可减少手动输入 SSID 的需要，也能让 App 在完成配网后立即在目标局域网发现机器人。

### 3.4 设备主页

连接成功后进入设备主页。这里是单台机器人的功能入口：

- **运行模式**：选择遥控模式或导览模式；
- **状态自检**：查看机器人诊断数据；
- **固件管理升级**：检查并安装机器人软件包；
- 右上角更多菜单：可进入设置或远程协助（视连接与权限而定）。

![设备主页](../assets/control/app-guide-2026/device-home.png)

## 4. 运行模式与遥控

### 4.1 选择运行模式

设备主页的 **运行模式** 会先显示模式选择面板：

- **遥控模式**：使用虚拟摇杆或外接手柄控制机器人；
- **导览模式**：按预设路线进行巡游；需先准备地图与路线。基础功能已经完成，正在进行内部测试和优化，后续将全量开放。

![运行模式选择](../assets/control/app-guide-2026/mode-picker.png)

### 4.2 遥控界面

进入 **遥控模式** 后，先确认视频/模型画面、网络和电量均正常，再按需要启用机器人。打开此页面并不等同于启动机器人，也不会自动产生运动指令。

| 区域 | 说明 |
| --- | --- |
| 左上 | 返回控制入口；**刷新视频** 可在 Wi-Fi 控制时重新建立或刷新视频画面；**状态检测** 可进入机器人状态诊断。 |
| 顶部右侧 | 显示网络质量（Wi-Fi 时通常为 RTT，蓝牙时通常为 RSSI）和电池状态，并提供 **启动机器人 / 停止机器人** 按钮。 |
| 中央 | 主视图区域。可在实时视频与 3D 数字孪生模型视图之间切换，用于从不同角度观察机器人状态。它不是机器人型号切换。 |
| 左右下角 | 两个虚拟摇杆，用于平移、转向和高度等控制；仅在机器人已启动且操作环境安全时使用。 |
| 右侧功能岛 | 提供常用操作、控制设置，以及手柄状态覆盖层入口。 |

![遥控界面](../assets/control/app-guide-2026/12-remote-control.png)

### 4.3 顶部功能与视图切换

左上角的 **刷新视频** 只用于刷新 Wi-Fi 控制下的视频流；画面未出现、卡住或网络恢复后需要重新拉取视频时可使用。蓝牙直连不提供视频流，因此不要将该按钮视为蓝牙连接诊断工具。

**状态检测** 是快速进入诊断的入口。它用于查看连接后机器人上报的状态；当发现电量、温度、关节或日志异常时，应先停止遥控操作、让机器人处于安全状态，再进入检查。

主视图旁的切换控件用于在 **实时视频** 与 **3D 数字孪生模型** 之间切换：

- 视频视图更适合确认机器人周边环境、落脚区域和实际姿态；
- 模型视图更适合观察姿态与关节状态；
- 两种视图都是观察方式，不会改变机器人型号、运行模式或控制参数。

### 4.4 手柄、虚拟摇杆与控制设置

遥控页支持虚拟摇杆、键盘和外接手柄。外接手柄可使用 USB 或蓝牙连接到运行 App 的手机、平板或 PC；连接后，可从右侧功能岛打开手柄状态覆盖层，确认手柄已连接及输入是否正常。

在 **设置 → 控制** 中可配置手柄启用、灵敏度、死区、平移/旋转输出范围和握持模式。首次使用手柄时，建议先在机器人停止状态下查看输入反馈，再从低速度档位开始试用。

!!! tip "避免残留输入"

    切换页面、窗口失去焦点或改用其他控制方式后，请松开手柄或让虚拟摇杆回中，并确认机器人没有继续接收运动输入后再继续操作。

### 4.5 启动、停止与安全提醒

顶部右侧的 **启动机器人** 用于使机器人进入可执行控制指令的状态；按钮变为 **停止机器人** 后可用于结束该状态。网络质量和电池图标仅反映通信及电量信息，不能替代对现场与机械状态的判断。

!!! danger "启动前必检"

    仅当机器人位于空旷、平整且受控的区域时才可启动。启动前确认：人员和障碍物已离开运动范围；机器人姿态正常、无缠绕或悬空部件；电池和网络满足任务需要。启动后先以低速、小幅度验证控制方向。停止机器人后，也不要立即假定全部机械风险已消除，应等待机器人稳定并按现场安全规范处置。

!!! danger "启动与运动控制"

    只有在确认环境安全并了解摇杆映射后，才可点击 **启动机器人** 或操作摇杆。进入遥控页面本身不会启动机器人。

## 5. 设置

在遥控页右侧快捷设置入口，或从个人中心进入 **设置**。设置页含以下标签：

- **控制**：速度档位、摇杆灵敏度、摇杆死区、平移与旋转输出范围、手柄启用及握持模式；
- **视频**：视频质量和视频统计显示；
- **开发者**：仅在解锁开发者模式后显示，用于开发与排障。

左下角的 **导入、导出与重置** 可管理本地设置；导入前请确认配置来源可信。

![控制参数设置](../assets/control/app-guide-2026/13-settings-control.png)

## 6. 状态自检

状态自检通过 Wi-Fi 连接读取机器人运行数据。首次进入时需要确认 **DOMAIN_ID**；该值必须与机器人正在运行的 ROS 2 通信域一致。

![设置 DOMAIN_ID](../assets/control/app-guide-2026/status-domain.png)

诊断中心提供以下页面：

| 页面 | 内容 | 使用建议 |
| --- | --- | --- |
| 日志 | 实时查看机器人日志 | 日志可能包含设备信息，导出前先检查内容 |
| 电池 | 电压、电流、温度与趋势 | 作为运行前检查的一部分 |
| 关节温度 | 各关节温度状态 | 出现异常温度时停止高负载操作 |
| 3D 姿态 | 数字孪生姿态视图 | 用于观察姿态和关节状态 |
| 命令行 | SSH 终端 | 仅限具备维护权限的人员使用 |

![电池诊断页](../assets/control/app-guide-2026/17-status-battery.png)

### 6.1 状态检测总览

左侧设备信息区用于确认当前诊断目标及数据流状态，右侧按“查看”和“工具”分组进入具体页面。若显示“等待数据”或某项显示暂无数据，通常表示机器人尚未上报对应诊断数据；此时应先检查 Wi-Fi 连接、DOMAIN_ID 和机器人服务状态，而不是反复执行遥控操作。

![状态检测总览（设备信息已脱敏）](../assets/control/app-guide-2026/status-overview-redacted.png)

### 6.2 日志

进入 **日志** 可选择当前日志文件，并在页面内查看运行记录。日志常用于定位服务启动、连接、节点异常等问题；截图中的文件名和日志正文已脱敏。

!!! warning "日志包含敏感信息"

    日志可能包含机器人名称、IP 地址、目录、命令参数或运行标识。向售后或第三方发送日志前，请先确认其接收权限，并遮罩不必要的设备与网络信息。

![日志页（内容已脱敏）](../assets/control/app-guide-2026/status-logs-redacted.png)

### 6.3 关节温度

**关节温度** 用于查看各关节上报的温度数据。页面的筛选和翻页控件可用于浏览温度记录；若出现持续高温、异常波动或无数据，应停止高负载运动并按维护流程检查。当前测试截图为“暂无数据”的正常空状态示例，实际数值取决于机器人是否已上报该数据。

![关节温度页](../assets/control/app-guide-2026/status-joint-temperature.png)

### 6.4 SSH 命令行

点击 **命令行** 后，App 先显示 SSH 凭据页：填写已获授权的用户名和密码后，才可建立到机器人的安全命令行会话；“保存此机器人的密码”仅在需要本机记住凭据时选择。进入该页本身不会连接机器人，也不会执行命令。

!!! danger "仅限维护人员"

    SSH 命令可能修改机器人配置、停止服务或影响运行安全。仅在具备维护授权、清楚命令影响且机器人处于安全状态时使用；不要在文档、工单或聊天中分享密码、IP 地址、端口或完整终端输出。

![SSH 命令行连接页（设备信息已脱敏）](../assets/control/app-guide-2026/status-command-line-redacted.png)

## 7. 固件管理升级

固件管理入口位于设备主页的 **固件管理升级**，首页的 **固件升级** 则提供多台设备的批量升级入口。

### 7.1 检查升级包

进入页面后，App 读取每个软件包的当前版本、目标版本和下载大小。带有更新提示的软件包可单独升级，或加入“升级所选”。

![固件管理升级](../assets/control/app-guide-2026/firmware-management.png)

### 7.2 确认升级

点击单独升级或升级所选后，先核对将安装的软件包、版本和大小。确认页中的 **开始升级** 会实际向机器人提交升级任务。

![确认升级](../assets/control/app-guide-2026/firmware-package-detail.png)

!!! warning "升级前检查"

    - 机器人必须保持稳定供电和网络连接；
    - 升级时不要关闭 App、断开网络或强制重启机器人；
    - 升级完成后如页面提示需要重启，请在机器人静止且安全时执行；
    - 多台设备批量升级前，建议先在一台测试机器人上验证。

## 8. 远程协助

远程协助只在已通过 **Wi-Fi** 连接机器人时提供；蓝牙直连不显示该入口。

### 8.1 入口

1. 进入目标机器人的设备主页；
2. 点击右上角的 **更多**（三个点）；
3. 选择 **远程协助**。

App 会把当前机器人的地址、显示名称与序列号带入远程协助页，并尝试建立该机器人的网络会话。未选择当前机器人时，远程协助页会先显示局域网与历史设备列表，供用户选择目标设备。

![设备主页中的远程协助入口](../assets/control/app-guide-2026/remote-assist-entry-redacted.png)

### 8.2 请求协助

远程协助页分为三个阶段：

1. **连接机器人**：确认目标设备在线并建立 WebSocket 会话；
2. **检查状态**：显示设备身份、机器人连接状态及网络连通性检查；
3. **请求协助**：阅读并同意授权说明后，点击“请求协助”向机器人发起协助请求，并在会话面板查看请求、进行中和关闭状态。

![远程协助状态检查](../assets/control/app-guide-2026/remote-assist-page-redacted.png)

点击 **请求协助** 后，App 会显示授权说明。说明中包含可授予给支持人员的权限：通过反向 SSH 隧道通信、读取必要的诊断信息（如系统日志、控制状态、传感器数据），以及在授权范围内启动或停止机器人服务。只有点击 **同意并请求** 才会真正创建会话。

![远程协助授权说明](../assets/control/app-guide-2026/remote-assist-consent-redacted.png)

### 8.3 会话由机器人端维持

远程协助的通道在机器人端服务获授权后启动；手机、平板或 PC 端 App 负责发起授权、显示会话状态和提供关闭入口。会话可以跨 App 页面切换和网络重连恢复；即使 App 重启，只要机器人端会话仍有效，重新进入远程协助页后也能查询到状态。

这意味着协助建立后，控制设备无需一直停留在远程协助页面。但协助期间应保持网络可用，避免强制停止 App；要结束协助，请使用会话中的关闭操作。机器人下电或主动关闭会话后，通道会被销毁。

会话就绪后，状态面板会显示剩余可用时间，并提供 **延时 +30 分** 与 **立即关闭**。端口、剩余时间和连接标识均为动态会话信息，不应公开分享。

![远程协助会话就绪状态](../assets/control/app-guide-2026/remote-assist-session-redacted.png)

!!! warning "远程协助授权"

    请求协助前，请确认授权对象和现场状态。远程协助会开放排障所需的机器人会话；未明确授权时不要点击“请求协助”。会话进行中可隐藏状态面板，并通过页面浮动按钮再次打开。

## 9. 个人中心、关于与服务页

首页的 **个人中心** 包含以下功能：

- 官网链接与工单入口；工单服务需要登录，且本地模式下会提示登录要求；
- 语言切换；
- 设置入口与手动检查 App 更新；
- **关于 BXI**：应用版本、开源许可证、隐私政策、服务条款、导出个人数据和撤回隐私同意；
- 已登录账户还可退出登录或注销账户。

开发者模式不会默认显示。当前实现中，连续点击“关于 BXI”中的版本号可解锁开发者设置；该模式仅应由开发或维护人员使用。

### 9.1 工单服务

入口为 **个人中心 → 工单服务**。工单属于云端账号服务：本地模式会显示“需要登录”，登录后才可查看未读数、创建工单和与支持人员沟通。

工单列表显示工单号、主题、分类、关联机器人、状态和最后更新时间；支持人员有新回复时，个人中心会显示未读提示。打开工单详情会自动标记为已读。

创建工单时需要填写：

1. 问题分类；
2. 主题和详细问题描述；
3. 联系邮箱；
4. 关联机器人（从已绑定机器人选择，或手动填写机器人序列号）；
5. 可选附件，例如照片、日志文件。

提交后可在详情页查看处理状态和消息记录，继续回复并附加文件。问题解决后，用户可确认关闭已解决工单。

!!! tip "提交高质量工单"

    请写明机器人型号/序列号、App 版本、网络环境、复现步骤、发生时间和错误提示。上传日志或截图前请先移除密码、令牌、内网地址等敏感信息。
